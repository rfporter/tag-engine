== Introduction

{product} gives a LabVIEW application a central store of named variables, called *tags*, like the
tag database in a SCADA system. Any part of the application can create, read, write or watch a tag
by name, without passing wires or queues between loops.

Each tag holds a value of any LabVIEW data type, a timestamp, and properties such as description,
units and limits. It also has two events: *ValChange*, fired when the value changes, and
*SetRequest*, which lets other code ask the tag's owner to change the value instead of writing it
directly. Tags can be locked so that set requests are blocked under certain conditions.

{product} was inspired by the NI Current Value Table and GPower VI Register toolkits, and adds
events, properties, locking and JSON configuration.

=== What's included

* *The {product} API*: create, find, read, write and destroy tags, by name or by reference.
* *Tag Expr*: math expressions that read tag values, written with `$\{TAG_NAME}` references.
* *JSON configuration*: save tag definitions to JSON and create tags from it.
* *Tag Watchlist*: a ready-made window for watching and changing tag values at run time.

=== Requirements

* LabVIEW 2020 or later
* muParser API for LabVIEW (`lv_muparser`) 3.1.2.1 or later, for Tag Expr
* JSONtext (`jdp_science_jsontext`) 1.9.1.125 or later

VI Package Manager installs the dependencies with the package.

=== Installation

Install the {product} package with VI Package Manager. The VIs are then on the
menu:Functions[Addons > {product}] palette.
