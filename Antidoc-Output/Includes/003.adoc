== +++Tag Watchlist.lvlib+++


*Responsibility:*
A window for watching and changing Tag values while an application runs, for debugging and commissioning.

Call Launch Tag Watchlist UI to open the window without blocking the caller. The other VIs are the window itself and its pop-ups.

*Version:* 1.0.0.0

|+++Tag_Value_Entry_PopUp+++

|image::Tag Watchlist.lvlib-Tag_Value_Entry_PopUp.vi.png[Tag Watchlist.lvlib:Tag_Value_Entry_PopUp.vi]
|Looks up a Tag by name and opens a value-entry pop-up that matches its type:
- Boolean: Value Entry_BOOL
- DBL and SGL: Value Entry_DBL
- I8, I16, I32: Value Entry_I32
- U8, U16, U32: Value Entry_U32
- String: Value Entry_STR
- Any other type: Value Entry_STR, editing the value as JSON

The entered value is converted back to the Tag's own type. Take care with JSON: invalid text returns an error.

If the user clicks OK, Apply is TRUE and the value is sent according to Write Type:
- SetRequest (default): sends a SetRequest. Synchronous and Timeout apply to it.
- WriteValue: writes the value directly. Use it for testing only.

If the Tag is not found, found is FALSE and the error from Get Tag is returned.

|+++Tag Watchlist UI+++

|image::Tag Watchlist.lvlib-Tag Watchlist UI.vi.png[Tag Watchlist.lvlib:Tag Watchlist UI.vi]
|The Tag Watchlist window. Use Launch Tag Watchlist UI to open it.

The left list shows every Tag that existed when the window opened. Type in Filter to show only matching names; the filter is not case-sensitive and uses Match Pattern syntax. Double-click a Tag, or right-click and choose Add to Watch, to add it to the watchlist.

The watchlist updates every 200 ms with each Tag's value, the time of its last change, units, description and Stale flag. Double-click a row to send a SetRequest. Right-click a row to:
- send a SetRequest (Request Value Change),
- write the value directly (Force Value Change; for testing only),
- show the Tag's details,
- remove it from the watchlist.

The window closes on its own close button or when Shutdown Event is generated.
