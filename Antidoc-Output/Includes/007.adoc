== +++Tag.lvclass+++


*Responsibility:*
A named, typed value with a timestamp and a set of standard properties. Tag is the basic data item of the Tag Engine.

**Value**
The value is stored as a variant. Its data type is fixed by the initial value passed to Construct. Each write records a timestamp, and a Tag can be marked Stale when its value is out of date.

**Properties**
Each Tag carries named properties: description, units, min, max, default, initial, formatString, rank and elementType. Construct fills in defaults from the initial value's type. Properties can be read and written with the accessor VIs, or by name with Get/Set Property by Name.

**Events**
- ValChange: fired after the value changes, carrying the old and new value and timestamp. Enabled by Read ValChange.
- SetRequest: lets other code ask the Tag's owner to set a new value, optionally waiting for confirmation. Enabled by Read SetRequest Event, sent by Write SetRequest.

**Locking**
Set Lock and Release Lock add and remove named locks. While any lock is held, Write SetRequest refuses requests unless Ignore Lock is set.

*Version:* 1.0.0.3

|image::Tag Engine Core.lvlib-Tag.lvclass-Write SetRequest.vi.png[Tag Engine Core.lvlib:Tag.lvclass:Write SetRequest.vi]
|Asks the Tag's owner to set a new value, by firing the SetRequest event.

If the Tag is locked and Ignore Lock is FALSE, nothing is sent and an error listing the held locks is returned. If nobody has enabled SetRequest events, nothing happens.

If Synchronous is TRUE, the VI waits up to Timeout ms for the owner to confirm the request (timed out? reports a timeout). Source identifies who made the request.

Note: the value's type is not checked yet.
