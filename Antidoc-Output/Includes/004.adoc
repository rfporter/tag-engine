== +++Tag Engine Core.lvlib+++


*Responsibility:*
The core of the Tag Engine: the Tag class and the shared Tag registry, kept in their own library so they can be built into a packed project library (PPL).

- **Tag.lvclass**: a named, typed value with a timestamp, standard properties, change and set-request events, and named locks.
- **Tag Core.lvclass**: the single registry of all Tags, which hands them out by name as data value references.
- **Types**: the data carried by the ValChange and SetRequest events.

Applications normally use the VIs in Tag Engine.lvlib rather than calling this library directly.

*Version:* 1.0.0.0
