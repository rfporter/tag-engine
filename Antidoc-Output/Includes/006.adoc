== +++Tag Core.lvclass+++


*Responsibility:*
A single, shared registry of all Tags in the application.

Tags are stored by name and handed out as data value references (DVRs), so all callers work on the same Tag. Names are not case-sensitive: they are stored and looked up in upper case.

Tags can be grouped into namespaces by giving them names like "Namespace:Name". The separator is set with Set Delimiter and defaults to ":".

Call Destruct at shutdown to destroy every Tag and the lookup table.

*Version:* 1.0.0.0
