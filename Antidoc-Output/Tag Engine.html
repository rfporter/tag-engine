Section 1. Project description

Tag Engine gives a LabVIEW application a central store of named variables, called tags, like the tag database in a SCADA system. Any part of the application can create, read, write or watch a tag by name, without passing wires or queues between loops.

Each tag holds a value of any LabVIEW data type, a timestamp, and properties such as description, units and limits. It also has two events: ValChange, fired when the value changes, and SetRequest, which lets other code ask the tag’s owner to change the value instead of writing it directly. Tags can be locked so that set requests are blocked under certain conditions.

It was inspired by the NI Current Value Table and GPower VI Register toolkits, and adds events, properties, locking and JSON configuration.

Features:

  • Any data type: values are stored as variants. The type is fixed by the initial value, and malleable VIs read and write values in their native type.

  • Access by name or reference: look tags up by name (not case-sensitive), or keep the tag’s reference for faster access.

  • Namespaces: group tags as Namespace:Name; the separator can be configured.

  • Events: ValChange on every write, with old and new values. SetRequest for requested changes, optionally synchronous with a timeout, and tagged with the requester’s Source.

  • Locking: named locks block SetRequests (error 5611) until every lock is released, so requests can be refused under certain conditions. Direct writes are not affected.

  • Properties: description, units, min, max, default, format string and more, filled in automatically from the tag’s data type. Custom properties can be added too.

  • Staleness and timestamps: every value carries the time of its last write and a Stale flag.

  • JSON configuration: save and restore tag definitions as JSON.

  • Expressions: use tags in math expressions with ${TAG_NAME} syntax, through the Tag Expr library (built on muParser).

  • Watchlist UI: a ready-made window to watch and edit tag values at run time.

  • PPL-ready: the core (Tag Engine Core.lvlib) is kept separate so it can be built into a packed project library.

4.2. Tag Core.lvclass

Responsibility: A single, shared registry of all Tags in the application.

Tags are stored by name and handed out as data value references (DVRs), so all callers work on the same Tag. Names are not case-sensitive: they are stored and looked up in upper case.

Tags can be grouped into namespaces by giving them names like "Namespace:Name". The separator is set with Set Delimiter and defaults to ":".

Call Destruct at shutdown to destroy every Tag and the lookup table.

4.3. Tag.lvclass

Responsibility: A named, typed value with a timestamp and a set of standard properties. Tag is the basic data item of the Tag Engine.

Value The value is stored as a variant. Its data type is fixed by the initial value passed to Construct. Each write records a timestamp, and a Tag can be marked Stale when its value is out of date.

Properties Each Tag carries named properties: description, units, min, max, default, initial, formatString, rank and elementType. Construct fills in defaults from the initial value’s type. Properties can be read and written with the accessor VIs, or by name with Get/Set Property by Name.

Events - ValChange: fired after the value changes, carrying the old and new value and timestamp. Enabled by Read ValChange. - SetRequest: lets other code ask the Tag’s owner to set a new value, optionally waiting for confirmation. Enabled by Read SetRequest Event, sent by Write SetRequest.

Locking Set Lock and Release Lock add and remove named locks. While any lock is held, Write SetRequest refuses requests unless Ignore Lock is set.

Turns the Tag’s configuration (name, type, typeString and all properties) into a JSON string, for example to save it to a configuration file.

Unflatten from JSON Config

Rebuilds a Tag from JSON made by Flatten to JSON Config. It reads the name, type and properties (decoding the Base64-encoded values), then constructs the Tag with the stored initial value.

Set Lock

Adds a lock named LockName to the Tag and sets Locked to TRUE. A Tag can hold several named locks, and stays locked until all of them are released.

Release Lock

Removes the lock named LockName. Locked becomes FALSE when no locks are left.

Get Property by Name

Returns the property named Name. If it doesn’t exist, Found? is FALSE and error 5602 ("Property "<name>" not found.") is returned.

Set Property by Name

Creates or overwrites the property named Name. Replaced? is TRUE if an existing property was overwritten.

Set Properties from Initial

Helper for Construct. Works out the Tag’s data type from Initial Value and fills in default properties: initial, min/max (the type’s range), rank, elementType, formatString and default. Properties already in Properties in are kept.

Write SetRequest

Asks the Tag’s owner to set a new value, by firing the SetRequest event.

If the Tag is locked and Ignore Lock is FALSE, nothing is sent and an error listing the held locks is returned. If nobody has enabled SetRequest events, nothing happens.

If Synchronous is TRUE, the VI waits up to Timeout ms for the owner to confirm the request (timed out? reports a timeout). Source identifies who made the request.

Note: the value’s type is not checked yet.

Write Value with Timestamp

Writes a new value with the given timestamp. If no timestamp is given (zero), the current time is used. If IgnoreIfEqual is TRUE, the write is skipped when the new value equals the current one.

After a successful write, a ValChange event is fired if the event is enabled. The event carries the old and new value and timestamp.

Destruct

Destroys the Tag’s ValChange and SetRequest user events. Call it when the Tag is no longer needed.

Construct

Initializes the Tag object. The input initial value will define the type.

The input Tag name is checked. Illegal characters are removed and error 5609 is returned. Names longer than 256 characters are truncated and error 5610 is returned. Valid characters are: a-z A-Z 0-9 : _ / . -

Additional properties can be passed in as attributes of the properties variant.

4.4. Tag Expr.lvclass

Responsibility: A math expression that can read Tag values. Extends the mupExpr class from the muParser library.

Tags are referenced in the expression as ${TAG_NAME}, for example "${Tank1:Level} * 2 + offset". Tag names are not case-sensitive. Other variables and constants work as in mupExpr.

Usage: Construct once (this finds every Tag and keeps its reference), call Tag Expr Eval as often as needed (each call reads the Tags' current values), then Destruct.

Any mupExpr Eval VI can be used instead of Tag Expr Eval, as long as Lookup Tag Values is called first to read the current Tag values.

Tag values are converted to DBL for evaluation. See Lookup Tag Values for the supported types.

Version: 1.0.0.3

Read ExpressionWithTags

Construct

Creates a Tag Expr from an expression that can contain Tags, written as ${TAG_NAME}.

Each ${…​} is replaced with a placeholder variable (TAG00, TAG01, …​) before the expression is passed to muParser. The same Tag used more than once gets the same placeholder. Each Tag is looked up with Get Tag and its reference and data type are stored, so the Tags must exist before Construct is called. If a Tag is not found, the expression is destroyed and the error from Get Tag (5602) is returned.

Variable Names returns the Tag names (in upper case), followed by any other variables in the expression.

Optionally input a list of constant name-value pairs.

Set "Use system decimal point" to true to use the system’s decimal point. If it is a comma, the argument separator becomes a semicolon. The defaults are a period and a comma.

Bulk Size sets the data-set size for bulk mode evaluation. Default is 1 (single result).

Destruct

Destroys the Tag Expr and releases the muParser handle and variable pointers. The Tags it uses are not affected.

exprparse

Finds every ${TAG_NAME} in the expression and replaces it with a placeholder variable name that muParser accepts (TAG00, TAG01, …​). The same Tag used more than once gets the same placeholder.

Returns the modified expression, the unique Tag names (in upper case) and their placeholders, in matching order.

Used by Construct.

Lookup Tag Values

Reads the current value of every Tag in the expression and loads it into the matching expression variable, converted to DBL.

Supported types: - Boolean (TRUE = 1, FALSE = 0) - Signed and unsigned integers, including unsigned enums - Floating point, including numbers with units, and fixed point - Timestamp (seconds since the LabVIEW epoch) - String, which must use a period as the decimal point

A Tag of any other type returns error 5605 and stops the lookup. The expression should not be evaluated after an error.

The data type of each Tag is read once, in Construct.

Tag Expr Eval

Reads the Tags' current values (Lookup Tag Values) and evaluates the expression, returning a single result.

Boolean Result is TRUE when Result is non-zero. It is FALSE when Result is 0 or NaN.
